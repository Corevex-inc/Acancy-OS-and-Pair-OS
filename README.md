# Acancy-OS-and-Pair-OS
Pair OS, AçanCY OS ile entegre çalışan, iOS benzeri modern arayüz hedefleyen deneysel bir işletim sistemi projesidir. AçanCY’nin mikro çekirdek yapısını temel alır ve Pair OS ile birlikte mobil ve masaüstü deneyimini birleştiren, modüler ve genişletilebilir bir ekosistem oluşturmayı amaçlar.
# Pair OS

Pair OS, AçanCY OS ekosistemiyle birlikte çalışan, modern ve modüler bir işletim sistemi arayüz/katman projesidir. Amaç, iOS benzeri akıcı bir kullanıcı deneyimini AçanCY’nin mikro çekirdek tabanlı yapısı üzerine inşa etmektir.

## Proje Hakkında

Pair OS, AçanCY OS’nin çekirdek sistemini değiştirmeden onun üstünde çalışan bir “kullanıcı deneyimi katmanı” gibi tasarlanır. Böylece hem masaüstü hem mobil cihazlarda tutarlı, hızlı ve esnek bir yapı hedeflenir.

## AçanCY OS ile İlişki

- AçanCY OS: Sistem çekirdeği (mikro kernel + temel servisler)
- Pair OS: Kullanıcı arayüzü + deneyim katmanı
- Birlikte: Tam bir ekosistem (çekirdek + UI + uygulama sistemi)

## Özellikler (Planlanan)

- iOS benzeri akıcı arayüz tasarımı
- Alt navigasyon barı + üst kontrol paneli
- Modüler uygulama sistemi
- Hafif ve hızlı UI engine
- Genişletilebilir tema desteği
- Dokunmatik ve klavye uyumluluğu

## Vizyon

Pair OS, sadece bir arayüz değil; AçanCY OS üzerine kurulmuş “gelecek nesil deneyim katmanı” olmayı hedefler. Basitlik, hız ve esneklik ana felsefedir.

# Acancy-OS-and-Pair-OS

Pair OS is an experimental operating system interface layer project integrated with Acancy OS, aiming for a modern, iOS-like user experience. It is based on Acancy’s microkernel architecture and aims to build a modular and extensible ecosystem that combines both mobile and desktop experiences through Pair OS.

# Pair OS

Pair OS is a modern and modular operating system interface/layer project that works together with the Acancy OS ecosystem. The goal is to build a smooth, iOS-like user experience on top of Acancy’s microkernel-based structure.

## About the Project

Pair OS is designed as a “user experience layer” that runs on top of Acancy OS without modifying its core system. This allows a consistent, fast, and flexible structure across both desktop and mobile devices.

## Relationship with Acancy OS

- Acancy OS: System kernel (microkernel + core services)
- Pair OS: User interface + experience layer
- Together: A full ecosystem (kernel + UI + application system)

## Planned Features

- Smooth and modern user interface design
- Bottom navigation bar + top control panel
- Modular application system
- Lightweight and fast UI engine
- Expandable theme support
- Touch and keyboard compatibility

## Vision

Pair OS is not just an interface; it aims to become a next-generation experience layer built on top of Acancy OS. Simplicity, speed, and flexibility are the core philosophy.
